Screenshot utility that can capture fairplay-protected content

Kernel offsets are hardcoded for 18.6.2 build 22G100 (iPad7,11)

The kernel-access code in `clearsword/` is adapted from [ClearSword by TheRealClarity](https://github.com/TheRealClarity/ClearSword)
